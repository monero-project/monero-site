# Overview

This is the v0.18.5.4 release of the Monero software. This is a minor release that includes bug fixes.

Some highlights of this minor release are:

- Daemon: fix DNSSEC validation for checkpoints, blocklists and update checks ([#11542](https://github.com/monero-project/monero/pull/11542))
- RPC: restore string-to-integer conversion in JSON requests (to be removed in v0.19 as a breaking change) ([#11552](https://github.com/monero-project/monero/pull/11552))

The complete list of changes is [available on GitHub](https://github.com/monero-project/monero/compare/v0.18.5.3...v0.18.5.4), along with [the source code](https://github.com/monero-project/monero/tree/v0.18.5.4).
