# Overview

This is the v0.18.5.3 release of the Monero GUI software. This is a highly recommended release that includes a large number of bug fixes.

[The latest CLI release notes can be found on the precedent blog post]({{ site.baseurl_root }}/2026/10/05/monero-0.18.5.3-released.html)

Some highlights of this release are:

- Add more fiat currency options ([#4714](https://github.com/monero-project/monero-gui/pull/4714))
- Fix transaction history sorting ([#4693](https://github.com/monero-project/monero-gui/pull/4693))
- Fix stale transactions in send confirmation dialog ([#4690](https://github.com/monero-project/monero-gui/pull/4690), [#4720](https://github.com/monero-project/monero-gui/pull/4720))
- Keep daemon credentials scoped to each connection ([#4709](https://github.com/monero-project/monero-gui/pull/4709))
- Fix SOCKS5 proxy handling and proxy use for update verification ([#4681](https://github.com/monero-project/monero-gui/pull/4681), [#4682](https://github.com/monero-project/monero-gui/pull/4682), [#4707](https://github.com/monero-project/monero-gui/pull/4707), [#4710](https://github.com/monero-project/monero-gui/pull/4710))
- Fix fiat price updates and update checks on Linux ([#4725](https://github.com/monero-project/monero-gui/pull/4725))
- Abort saving wallets if setting the password fails ([#4645](https://github.com/monero-project/monero-gui/pull/4645))
- Fix restore height when entering dates without hyphens ([#4672](https://github.com/monero-project/monero-gui/pull/4672))
- Show key type when verifying signed messages ([#4687](https://github.com/monero-project/monero-gui/pull/4687))
- Improve display of transactions with multiple recipients ([#4692](https://github.com/monero-project/monero-gui/pull/4692))
- Display reserve proof amounts in XMR ([#4719](https://github.com/monero-project/monero-gui/pull/4719))
- Fix QR code scanning from the screen on macOS ([#4663](https://github.com/monero-project/monero-gui/pull/4663))
- Update P2Pool to v4.18.1 ([#4715](https://github.com/monero-project/monero-gui/pull/4715))
- Minor bug fixes

The changes included in the release tag are [available on GitHub](https://github.com/monero-project/monero-gui/compare/v0.18.5.2...v0.18.5.3), along with [the source code](https://github.com/monero-project/monero-gui/tree/v0.18.5.3).
