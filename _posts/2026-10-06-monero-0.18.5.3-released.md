# Overview

This is the v0.18.5.3 release of the Monero software. This is a highly recommended release that includes a large number of bug fixes.

Some highlights of this release are:

- Daemon: fix P2P connection stalls ([#10918](https://github.com/monero-project/monero/pull/10918))
- Daemon: restore transaction relay after restart ([#10845](https://github.com/monero-project/monero/pull/10845))
- Daemon: improve block relay handling ([#11299](https://github.com/monero-project/monero/pull/11299), [#11301](https://github.com/monero-project/monero/pull/11301))
- Daemon: improve duplicate handshake and timeout handling ([#11157](https://github.com/monero-project/monero/pull/11157), [#11305](https://github.com/monero-project/monero/pull/11305))
- Daemon: group public IPv6 connection limits by /64 ([#11013](https://github.com/monero-project/monero/pull/11013))
- Daemon: flush rejected block spans from disconnected peers ([#11145](https://github.com/monero-project/monero/pull/11145))
- Daemon: improve transaction serialization and validation ([#11302](https://github.com/monero-project/monero/pull/11302), [#11349](https://github.com/monero-project/monero/pull/11349), [#11360](https://github.com/monero-project/monero/pull/11360), [#11372](https://github.com/monero-project/monero/pull/11372))
- Daemon: limit output offsets cache size ([#11303](https://github.com/monero-project/monero/pull/11303))
- Daemon: improve LMDB resizing and transaction handling ([#10946](https://github.com/monero-project/monero/pull/10946), [#11159](https://github.com/monero-project/monero/pull/11159), [#11205](https://github.com/monero-project/monero/pull/11205), [#11290](https://github.com/monero-project/monero/pull/11290))
- Daemon: disable `get_transaction_pool` in restricted mode ([#10973](https://github.com/monero-project/monero/pull/10973))
- Daemon: improve restricted RPC privacy filtering ([#11034](https://github.com/monero-project/monero/pull/11034), [#11147](https://github.com/monero-project/monero/pull/11147))
- Daemon: restrict `get_public_nodes` to public zone peers ([#11356](https://github.com/monero-project/monero/pull/11356))
- Daemon: reject deep block submissions on restricted RPC ([#11239](https://github.com/monero-project/monero/pull/11239))
- ZMQ: recover from oversized requests ([#10959](https://github.com/monero-project/monero/pull/10959))
- ZMQ: hide request contents from logs in restricted mode ([#10971](https://github.com/monero-project/monero/pull/10971))
- Wallet: improve transaction validation for cold and multisig signing ([#11192](https://github.com/monero-project/monero/pull/11192), [#11332](https://github.com/monero-project/monero/pull/11332))
- Wallet: erase all copies of multisig nonces together ([#11331](https://github.com/monero-project/monero/pull/11331))
- Wallet: fix multisig output import and refresh handling ([#11078](https://github.com/monero-project/monero/pull/11078), [#11464](https://github.com/monero-project/monero/pull/11464))
- Wallet: speed up refresh for old accounts ([#10856](https://github.com/monero-project/monero/pull/10856))
- Wallet: fix stale transfer maps after output imports ([#11463](https://github.com/monero-project/monero/pull/11463))
- Wallet: fix inconsistent transaction public key handling ([#11458](https://github.com/monero-project/monero/pull/11458))
- Wallet: validate key image domain in reserve proofs ([#11153](https://github.com/monero-project/monero/pull/11153))
- Wallet: fix payment ID display and classification ([#10894](https://github.com/monero-project/monero/pull/10894), [#11461](https://github.com/monero-project/monero/pull/11461))
- Wallet: hardening against malicious remote nodes ([#10950](https://github.com/monero-project/monero/pull/10950), [#11320](https://github.com/monero-project/monero/pull/11320), [#11347](https://github.com/monero-project/monero/pull/11347), [#11444](https://github.com/monero-project/monero/pull/11444))
- Wallet: preserve required SSL when allowing chained certificates ([#11336](https://github.com/monero-project/monero/pull/11336))
- Wallet: improve refresh and shutdown handling ([#11135](https://github.com/monero-project/monero/pull/11135), [#11151](https://github.com/monero-project/monero/pull/11151), [#11173](https://github.com/monero-project/monero/pull/11173))
- Wallet: fix infinite loop when estimating transactions with many outputs ([#11184](https://github.com/monero-project/monero/pull/11184))
- Wallet: keep received amount breakdown consistent ([#11449](https://github.com/monero-project/monero/pull/11449))
- Wallet RPC: add transaction weight to `describe_transfer` ([#11112](https://github.com/monero-project/monero/pull/11112))
- Wallet RPC: improve automatic refresh and shutdown handling ([#10955](https://github.com/monero-project/monero/pull/10955), [#11139](https://github.com/monero-project/monero/pull/11139))
- Wallet RPC: reject `--password` with `--wallet-dir` ([#11258](https://github.com/monero-project/monero/pull/11258))
- Trezor: validate bridge response size before parsing ([#10989](https://github.com/monero-project/monero/pull/10989))
- RandomX: update to v1.2.3 ([#10926](https://github.com/monero-project/monero/pull/10926))
- Prevent log injection from malformed JSON and HTTP headers ([#11149](https://github.com/monero-project/monero/pull/11149), [#11225](https://github.com/monero-project/monero/pull/11225))
- Fix HTTP connection reuse after remote disconnects ([#11115](https://github.com/monero-project/monero/pull/11115))
- Various bug fixes and improvements

The complete list of changes is [available on GitHub](https://github.com/monero-project/monero/compare/v0.18.5.1...v0.18.5.3), along with [the source code](https://github.com/monero-project/monero/tree/v0.18.5.3).
